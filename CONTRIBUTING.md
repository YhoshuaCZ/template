# Contributing to Proyect Name

Thank you for your interest in contributing to Proyect Name!

## Development Workflow
1. Fork the repository.
2. Create a new feature branch (`git checkout -b feature/your-feature-name`).
3. Ensure your code follows the Domain-Driven Design (DDD) architecture established in the project.
4. Commit your changes (`git commit -m 'feat: add new feature'`).
5. Push to the branch (`git push origin feature/your-feature-name`).
6. Open a Pull Request.

## Coding Standards
- Use **Angular Signals** for state management.
- Follow English naming conventions for all programming objects (classes, interfaces, methods, variables).
- Apply **TSDoc** comments to all classes, interfaces, and methods.
- Maintain accessibility (a11y) standards including ARIA labels on all structural HTML elements.
- Ensure strict separation of concerns across Domain, Application, Infrastructure, and Presentation layers.
